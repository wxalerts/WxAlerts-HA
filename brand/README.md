# Brand assets

`icon.png` (256×256) is the WxAlerts integration icon, kept here for a
submission to [home-assistant/brands](https://github.com/home-assistant/brands).

Home Assistant serves integration icons from that repository, not from the
custom component, so this file is not shipped to users — HACS only installs
`custom_components/wxalerts/`. Until the brands PR lands, the integration
shows the default placeholder icon.
